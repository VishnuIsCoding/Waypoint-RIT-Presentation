**WAYPOINT RIT: The Indoor Spatial Engine By Team Binary (Rajalakshmi Institute of Technology)**

🚀 **The Elevator PitchWaypoint RIT** is a high-precision, macro-to-micro indoor positioning system. It solves the "GPS Deadzone" problem by seamlessly transitioning users from a 3D interactive campus map into highly detailed, 2D indoor floor plans. By combining a FastAPI backend with OpenCV computer vision, Waypoint creates an "Indoor GPS" that guides students and visitors to exact rooms, labs, and faculty cabins without relying on satellite signals.

⚠️**The Problem** Standard navigation tools like Google Maps bring you to the RIT campus gate, but the moment you step inside a building, standard GPS fails. It cannot tell if a user is on Floor 1 or Floor 2, nor can it route a lost first-year student down a specific corridor to find a specific lecture hall (like LH-201) or locate a faculty member's cabin during an urgent situation.

💡 **Our Innovation**: Checkpoint AnchoringInstead of relying on expensive hardware like ceiling-mounted Bluetooth beacons or WiFi triangulation routers, Waypoint shifts the positioning logic entirely into software.We deployed a network of physical QR codes across the campus walls. When a user scans a QR code using our web app, OpenCV decodes the string and pings our MySQL/FastAPI database. The system instantly translates that string into exact $(X, Y)$ pixel coordinates and drops a live "You Are Here" pin onto a custom Figma-designed floor plan.

✨ **Core Features Macro-to-Micro UI:** Users start with a bird's-eye 3D Mapbox view of the entire RIT campus. Clicking a building dynamically collapses the 3D view and overlays a high-fidelity 2D floor plan.OpenCV "Indoor GPS": Absolute indoor positioning achieved through QR anchor scanning, bypassing the need for satellite GPS.The "Faculty Hunt" Engine: A relational database that links faculty members to specific rooms, allowing students to search a professor's name and instantly see a pin drop on their current cabin.Dynamic Event Routing: Because the map is powered by a live database, admins can instantly reroute traffic or update room statuses during dynamic events like college hackathons or semester exams.🛠️ The Tech StackFrontend & UI: Streamlit, Mapbox GL JS, HTML/CSS (Glassmorphism UI), Folium, Figma (for 2D spatial overlays).Backend & Data: FastAPI, Python, MySQL, SQLAlchemy.Vision Engine: OpenCV, Python qrcode library.
