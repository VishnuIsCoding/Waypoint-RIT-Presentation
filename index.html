Navigate the Unmapped.

A high-precision, macro-to-micro indoor positioning system powered by OpenCV, Mapbox, and FastAPI.

System Roadblocks & Solutions

1. The "GPS Deadzone"

Google Maps brings you to the campus gate, but instantly fails indoors. It cannot route you down a specific corridor.

Solution: Using OpenCV to scan physical QR checkpoints, the app creates an "Indoor GPS" mapping exact (x, y) vectors.

2. The "Fresher Maze"

New students wander aimlessly trying to find specific labs like the AI Lab or LH-201, increasing campus anxiety.

Solution: The Streamlit macro-to-micro UI allows visual indoor-stepping before walking, creating clear paths.

3. The "Faculty Hunt"

Finding a professor urgently to resolve an issue involves knocking on multiple wrong cabin doors.

Solution: The MySQL database maps faculty to live locations. Search their name, and a pin drops on their current cabin.

4. Dynamic Routing

Printed maps are useless when hackathons or exam seating shifts at the last minute.

Solution: An admin backend running on FastAPI dynamically updates room statuses across the entire web app instantly.

Execution Architecture

01

User opens site ➔ 3D RIT Campus

The Tech: Streamlit loads `st_folium`. The map is centered on RIT's main coordinates.

The Look: The user sees the Mapbox 3D buildings showing the whole campus.

02

User searches ➔ "LH Block"

The Tech: A search bar is built using `st.text_input("Search Building or Room")`.

The Logic: The backend takes "LH Block", checks the SQLite/MySQL database, and returns the GPS coordinates for that specific building.

03

Map zooms ➔ Focus on LH Building

The Tech: Streamlit automatically updates the Folium map's center coordinates and increases the `zoom_start` level (e.g., from 16 to 19).

The Look: The map smoothly "flies" over to the LH Block and zooms in close.

04

User clicks ➔ Selects "Floor 2"

The Tech: A Streamlit UI element appears (like a dropdown `st.selectbox` or a floating button for floors: G, 1, 2, 3).

The Logic: When the user clicks "Floor 2", Streamlit updates its `st.session_state` to switch from the "Campus View" to the "Inside View".

05

Rooms appear ➔ LH201, LH202, AI Lab

The Tech: The 3D map hides. Folium's `ImageOverlay` takes over, projecting the clean 2D Figma floor plan of Floor 2.

The Look: The screen populates with interactive markers (pins). If they search for your specific branch (AIML-B), the map highlights LH201.
