Navigate the Unmapped.

A high-precision, macro-to-micro indoor positioning system powered by OpenCV, Mapbox, and FastAPI.

MODE: HYBRID OVERLAY

System Roadblocks & Solutions

[ SYSTEM_ERROR_01 ]

The "GPS Deadzone"

Google Maps brings you to the campus gate, but instantly fails indoors. It cannot route you down a specific corridor.

Resolved: Using OpenCV to scan physical QR checkpoints, the app creates an "Indoor GPS" mapping exact vectors without satellite signals.

[ SYSTEM_ERROR_02 ]

The "Fresher Maze"

New students wander aimlessly trying to find specific labs like the AI Lab or LH-201, increasing campus anxiety.

Resolved: The Streamlit macro-to-micro UI allows visual indoor-stepping before walking, creating clear, visual paths.

[ SYSTEM_ERROR_03 ]

The "Faculty Hunt"

Finding a professor urgently to resolve an issue involves knocking on multiple wrong cabin doors across blocks.

Resolved: The MySQL database maps faculty to live locations. Search their name, and a pin drops directly on their current cabin.

[ SYSTEM_ERROR_04 ]

Dynamic Routing

Printed maps are useless when hackathons or exam seating shifts at the last minute.

Resolved: An admin backend running on FastAPI dynamically updates room statuses across the entire web app instantly.

Execution Architecture

01

User opens site ➔ 3D RIT Campus

The Tech: Streamlit loads `st_folium`. The map is centered on RIT's main coordinates.

The Look: The user sees the Mapbox 3D buildings showing the whole campus.

02

User searches ➔ "LH Block"

The Tech: A search bar is built using `st.text_input("Search Building or Room")`.

The Logic: The backend queries the MySQL database and returns exact GPS bounding coordinates.

03

Map zooms ➔ Focus on LH Building

The Tech: Streamlit automatically updates the Folium map's center coordinates and zoom level.

The Look: The map smoothly "flies" over to the LH Block and zooms in close.

04

User clicks ➔ Selects "Floor 2"

The Tech: A Streamlit UI element appears (floating button for floors: G, 1, 2, 3).

The Logic: When clicked, Streamlit switches state from "Campus View" to "Inside View".

05

Rooms appear ➔ LH201, LH202, AI Lab

The Tech: The 3D map hides. Folium's `ImageOverlay` takes over, projecting the Figma floor plan.

The Look: The screen populates with interactive markers routing to specific classrooms.
