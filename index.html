Navigate the Unmapped.

A high-precision, macro-to-micro indoor positioning system powered by OpenCV, Mapbox, and FastAPI.

System Roadblocks & Solutions

1. The "GPS Deadzone"

Google Maps brings you to the campus gate, but instantly fails indoors. It cannot route you down a specific corridor.

Solution: Using OpenCV to scan physical QR checkpoints, the app creates an "Indoor GPS" mapping exact (x, y) vectors without satellites.

2. The "Fresher Maze"

New students wander aimlessly trying to find specific labs like the AI Lab or LH-201, increasing campus anxiety.

Solution: The Streamlit macro-to-micro UI allows visual indoor-stepping before walking, creating clear paths.

3. The "Faculty Hunt"

Finding a professor urgently to resolve an issue involves knocking on multiple wrong cabin doors.

Solution: The MySQL relational database maps faculty to live locations. Search their name, and a pin drops on their current cabin.

4. Dynamic Routing

Printed maps are useless when hackathons or exam seating shifts at the last minute.

Solution: An admin backend running on FastAPI dynamically updates room statuses across the entire web app instantly.

5. Emergency Access

In emergencies, finding the nearest exit or critical infrastructure is delayed by confusion.

Solution: Clean Figma 2D overlays instantly map restrooms, exits, and safety points based on user proximity.

Execution Architecture

01

Macro Initialization

Streamlit loads `st_folium`. The user sees the Mapbox 3D buildings covering the entire RIT campus.

02

Database Spatial Query

User searches "LH Block". The FastAPI backend queries the MySQL database and returns exact GPS bounding coordinates.

03

Camera Animation

Streamlit updates the Folium map center. The camera smoothly flies and zooms directly to the LH Block.

04

Micro Transition

User selects "Floor 2". Streamlit session state shifts, hiding the 3D map and loading the high-fidelity 2D Figma floor plan.

05

Live Interactive Markers

The screen populates with interactive pins routing directly to LH-201, LH-202, and the AIML Lab.
